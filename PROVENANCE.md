# Provenance

The executor, versioned data format, resource-aware packing, CPU reference,
tests, and build system were written for this repository. No third-party
source code is vendored. CUDA is an external build/runtime dependency and
retains its own license.

The CoS sample in `examples/cos_sample.cpp` adapts the graph-construction rules
from Boyuan Shi's earlier `cuda_test_DAG_no_MCMC` project (`dag_generator.h`).
The original project was consulted read-only. This repository does not include
its MCMC machinery, physical input tables, local paths, scheduler account
information, or saved simulation results. The sample is included under this
repository's MIT license with the author's approval.

The sample's domain background is combinatorial summation of Feynman diagrams;
see [Nature Communications, DOI 10.1038/s41467-024-52000-6](https://doi.org/10.1038/s41467-024-52000-6).
This repository focuses on executing a supplied graph. It does not claim a new
diagrammatic summation identity or an optimal graph-construction algorithm.

`data/diamond.dag` is a hand-checkable synthetic graph.
`data/cos_su2_n2.dag` is generated by the sample generator at order two.
Neither fixture contains research measurements or external datasets.
